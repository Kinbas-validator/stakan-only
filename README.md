# Stakan-only — стакан Lighter RH с пометкой premium-ордеров

Локальная веб-страница для торговли на Lighter (Robinhood Chain): видно, какие ордера в стакане
выставили premium-аккаунты, сколько объёма вашей рыночной заявки уйдёт к ним, как исполнилась ваша
последняя заявка и какая доля недельного объёма прошла с premium. Плюс счета и хеджи Robinhood ↔ Lighter Core
по адресу кошелька — без ручного ввода позиций.

## Запуск

Нужен Python 3.10+.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python server.py
```

Откроется http://127.0.0.1:8765. Адрес кошелька введите в шапке страницы (или сразу при запуске:
`--wallet 0x…`). Остановить — Ctrl+C. Другие параметры: `--port`, `--host`, `--no-browser`.

Сервер слушает только 127.0.0.1. Чтобы открыть страницу с другого компьютера, используйте SSH-туннель:
`ssh -L 8765:127.0.0.1:8765 user@server`.

## Что на странице

- **Тикер.** Только RWA и pre-IPO, которые торгуются и на RH, и на Lighter Core. ☆ — избранное,
  хранится в браузере.
- **Счета.** Robinhood, Core и «Всего на обоих»: деньги, позиции, плечо, расстояние до ликвидации,
  занятая маржа. Связки — по марк-цене и итог, если закрыть обе ноги по стакану сейчас.
- **Стакан.** Ровно N строк продаж и N строк покупок, полоса спреда всегда на одном месте.
  Строка — один ордер в порядке очереди. Цвета: зелёный — premium, белый — standard, жёлтый — plus,
  фиолетовый — ваш ордер, серый — владелец не определён. Белая метка слева — ордера, которые
  заберёт рыночная заявка на заданный объём.
- **Шорт / Лонг маркетом.** Какая доля рыночной заявки на заданный объём уйдёт premium-мейкерам.
  При доле ≥ порога карточка и соответствующая сторона стакана загораются зелёным (и звук, если включён).
- **Моя последняя заявка.** Все исполнения вашего последнего ордера: вся по premium, частично или нет.
- **Поток сделок и последние сделки рынка.** Доля premium-мейкеров и тейкеров за окно.
- **Мои хеджи.** Позиции обеих площадок по кошельку: вход по средним ценам, выход по стакану сейчас,
  заработок по спреду, итог закрытия, uPnL биржи, фандинг.
- **Мой аккаунт.** Неделя очков (пятница 15:00 → пятница 15:00 по Турции, UTC+3): объём, объём с premium,
  доля premium, разбивка по тикерам и сделки с типом контрагента.

Параметры стакана можно задать в адресе: `?market=TSLA&rows=20&size=5000&thr=80`.

## Как определяется premium

Тариф аккаунта виден по комиссии, которую он платит в сделке (единицы 1e-6 от объёма): 0 — standard,
50 (0,005%) — plus, больше — premium.

- **Ордера в стакане.** Сервер слушает публичную ленту сделок всех рынков RH и ведёт реестр тарифов
  аккаунтов в `data/tier_registry.json`. Реестр копится между запусками. Сразу после первого запуска
  у части ордеров владелец ещё «не определён» — пока этот аккаунт не поторгует.
- **Ваши сделки.** Лента сделок аккаунта комиссию контрагента не отдаёт. Для новых сделок она берётся
  сразу из публичной ленты. Для сделок, прошедших без запущенного сервера, — из транзакции
  (`/tx`, поля `tf`/`mf`), в фоне. При первом запуске так проверяется текущая неделя и последние
  150 сделок; пока проверка идёт, у таких сделок тип «?».

## Данные и лимиты

Всё хранится в `data/` (другая папка — переменная `STAKAN_DATA`): `config.json` (кошелёк),
`tier_registry.json`, `accounts/<индекс>/trades.jsonl` и `tx_fees.jsonl`. Ключи и пароли не нужны:
используются только публичные API Lighter без входа.

Lighter ограничивает запросы без входа по IP (около 60 в минуту на площадку). Все REST-запросы
сервера и страницы идут через общий бюджет в `lighter_api.py`. Фоновые запросы (комиссии из
транзакций) уступают срочным. Страница сама держит одно WebSocket-соединение — со стаканом
выбранного тикера.

## Устройство

| Файл | Что делает |
|---|---|
| `server.py` | HTTP-сервер: страница, данные для неё, поток сделок (SSE), выбор кошелька |
| `market.py` | тикеры, лента сделок RH и реестр тарифов, стаканы для хеджей, позиции и счета по кошельку |
| `account.py` | аккаунт по кошельку, докачка сделок и комиссий, недельная статистика |
| `lighter_api.py` | общий бюджет REST- и WS-запросов к Lighter |
| `web/index.html` | страница |
| `web/book.js` | расчёты страницы без DOM: раскладка стакана, рыночная заявка, итоги недели |
